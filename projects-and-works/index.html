SmartBarangay (Capstone Project)

A capstone project I built with my team. Residents can request barangay clearances, permits, file complaints, or reserve for events online instead of going in person.

HTML CSS JavaScript PHP MySQL
Source Code ↗

Why we built it

Getting anything from the barangay usually means showing up in person and waiting around, so my team and I wanted to move that whole process online for our capstone.

What it does

Residents can request a barangay clearance or permit, file a complaint, or reserve for an event, all from home. They get email and SMS updates on the status, and once a document is ready, another notification lets them know it's ready for pickup onsite. Event reservations follow a similar notification flow, just with a different process behind it.

Where it's at

We previously hosted the project and had it live for one year, but unfortunately, the hosting period has ended. For now, the project is available as source code only. Since GitHub Pages doesn't support PHP, we can't host the fully functional version there.

NyitikShop

A static Django e-commerce display for gaming and PC parts. Has login, signup, adding to cart, and checkout, but it's just a front-end, nothing actually processes.

Django Python Static Site
Source Code ↗

Why I built it

This was our final group project for Special Topic 2, where we were tasked with creating an e-commerce website using Django. The project gave us an opportunity to apply what we learned about Django and web development by building an e-commerce interface as a team.

What it does

The website features product listings, an add-to-cart feature, and a checkout interface. It is a static demonstration of an e-commerce experience, designed to showcase the website's interface and user flow rather than function as a fully operational online store.

About the game

'Am I?' mixes physical cards with a phone app. Everyone in the room is a suspect, but only 2 to 3 of them are real. Players use ability cards, evidence cards, and profile cards to narrow it down and try to identify who they actually are.

My part
